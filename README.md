# 3d models by me

## Repository has been archived and moved to different repositories. Check for them at https://github.com/benni-ben?tab=repositories.

This repository has 3d models made by me. You may use these for whatever you want. If you want me to make something, DM me on Discord or open an issue.


## Prerequisites

You will need [7Zip](https://www.7-zip.org/) to extract some of the archives in this repository. Big folders had to be archived because GitHub can't handle 7000 files being uploaded at once.:rage:

You will also need [Blender](https://www.blender.org/download/)(the best 3d software in the world fr) to open the `.blend` files in this repo.
